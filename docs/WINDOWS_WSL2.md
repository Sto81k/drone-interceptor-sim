# 🪟 Запуск на Windows через WSL2 (з нуля)

Проєкт працює тільки на Linux (Ubuntu 22.04). На Windows найпростіше отримати Ubuntu через **WSL2**:
це справжня Ubuntu всередині Windows, без перевстановлення системи й без віртуалок.
Вікна Gazebo та YOLO відкриваються як звичайні вікна Windows.

## Що потрібно

| | Мінімум | Рекомендовано |
|---|---|---|
| Windows | 10 версії 22H2 або 11 | Windows 11 |
| Оперативна пам'ять | 8 ГБ | 16 ГБ |
| Вільне місце на диску C: | 35 ГБ | 50 ГБ |
| Відеокарта | будь-яка з актуальним драйвером | NVIDIA (YOLO працюватиме на GPU) |

У BIOS має бути увімкнена віртуалізація (Intel VT-x / AMD-V / SVM). На більшості ноутбуків вона вже ввімкнена.
Перевірити: Диспетчер завдань → Продуктивність → ЦП → «Віртуалізація: Увімкнено».

---

## Крок 1. Встановити WSL2 та Ubuntu 22.04 (≈10 хв)

1. Натисніть **Пуск**, введіть `PowerShell`, клацніть правою кнопкою → **Запустити від імені адміністратора**.
2. Виконайте:
   ```powershell
   wsl --install -d Ubuntu-22.04
   ```
3. **Перезавантажте комп'ютер.**
4. Після перезавантаження відкриється вікно Ubuntu (або запустіть «Ubuntu 22.04» з меню Пуск).
   Придумайте **ім'я користувача** (латиницею, маленькими літерами) і **пароль**.
   Під час введення пароля символи не відображаються, це нормально. Цей пароль знадобиться для `sudo`.
5. Знову в PowerShell (від адміністратора) оновіть WSL. Це потрібно, щоб працювали вікна (WSLg):
   ```powershell
   wsl --update
   wsl --shutdown
   ```

> ⚠️ Версія має бути саме **22.04**. Ubuntu 24.04 не підходить: на ній немає ROS 2 Humble і Gazebo 11.
> Перевірити версію в Ubuntu: `lsb_release -a`.

## Крок 2. Дати WSL більше пам'яті (рекомендовано, 1 хв)

За замовчуванням WSL бере половину RAM. Для компіляції ArduPilot і Gazebo краще виділити більше.
У Windows створіть файл `C:\Users\<ВашеІм'я>\.wslconfig` (наприклад, у Блокноті; зверніть увагу на крапку на початку і на те, що розширення `.txt` не потрібне):

```ini
[wsl2]
# приблизно 60-70% вашої RAM
memory=10GB
swap=8GB
```
Потім у PowerShell: `wsl --shutdown` і знову відкрийте Ubuntu.

## Крок 3. Драйвер відеокарти

Встановіть **свіжий драйвер для Windows** з сайту NVIDIA / AMD / Intel. WSL використовує саме його.
❗ **Не встановлюйте** драйвери NVIDIA всередині Ubuntu: це зламає GPU у WSL.

Перевірити, що вікна працюють (в Ubuntu):
```bash
sudo apt update && sudo apt install -y x11-apps
xeyes          # має з'явитися вікно з очима; закрийте його
```
Для NVIDIA: `nvidia-smi` в Ubuntu має показати вашу відеокарту.

## Крок 4. Склонувати і встановити проєкт (40–90 хв, без вашої участі)

Усе далі робиться **у вікні Ubuntu**:
```bash
sudo apt update && sudo apt install -y git
cd ~
git clone https://github.com/Sto81k/drone-interceptor-sim.git
cd drone-interceptor-sim
./install.sh
```
Скрипт один раз спитає пароль і далі все зробить сам. Якщо щось обірвалося (інтернет, сон ноутбука),
просто запустіть `./install.sh` ще раз: він продовжить з того місця, де зупинився.

> ⚠️ Клонуйте саме в `~` (домашню папку Linux), **не** в `/mnt/c/...`.
> На диску Windows усе працює в 10 разів повільніше і ламаються права файлів.

## Крок 5. Запуск

**Закрийте вікно Ubuntu і відкрийте нове** (щоб підхопилися налаштування), потім:
```bash
cd ~/drone-interceptor-sim
./run_sim.sh
```
Далі див. [README](../README.md#-швидкий-старт).

## 💡 Корисне

- **Файли проєкту з Провідника Windows:** введіть в адресному рядку `\\wsl$\Ubuntu-22.04\home\<ім'я>\drone-interceptor-sim`.
- **VS Code:** встановіть у Windows VS Code і розширення **WSL**, потім в Ubuntu: `cd ~/drone-interceptor-sim && code .`
- **Зупинити Ubuntu повністю** (звільнити пам'ять): у PowerShell `wsl --shutdown`.
- **Копіювати/вставляти в терміналі Ubuntu:** `Ctrl+Shift+C` / `Ctrl+Shift+V` (або права кнопка миші).

## 🩹 Типові проблеми WSL

| Проблема | Рішення |
|---|---|
| `cannot open display` / вікна не з'являються | PowerShell: `wsl --update`, потім `wsl --shutdown`, відкрити Ubuntu знову. |
| Gazebo відкривається чорним або падає | У `setup_env.bash` розкоментуйте `export LIBGL_ALWAYS_SOFTWARE=1`, відкрийте новий термінал. |
| Gazebo дуже повільний | Нормально для слабких/інтегрованих GPU в WSL. Закрийте зайві програми; для максимальної швидкості див. «Альтернатива» нижче. |
| `$'\r': command not found` | Репозиторій склоновано у Windows. Видаліть його і склонуйте заново **в Ubuntu** (`cd ~ && git clone ...`). |
| Компілятор вбивається (`Killed`, `signal 9`) | Мало пам'яті: збільште `memory`/`swap` у `.wslconfig` (Крок 2). |
| `WslRegisterDistribution failed 0x80370102` | Увімкніть віртуалізацію в BIOS. |

## Альтернатива: справжня Ubuntu (dual boot)

Якщо потрібна максимальна продуктивність Gazebo, встановіть **Ubuntu 22.04** другою системою
поруч з Windows (завантажувальна флешка через Rufus + образ з ubuntu.com).
Далі ті самі команди з Кроку 4. VirtualBox/VMware **не рекомендуються**: 3D-прискорення там погане.
